# 银发小鸡骑士 · 召唤之约

操控银发铠甲小鸡骑士，以剑技、招架与篮球穿过十二章旅途。每章有不同地形、机关与敌人组合。先召唤王果冻，再靠近骑乘，最后击败恶龙，救出蔡乙先王子。

## 打开游戏

保留整个游戏文件夹，双击 `index.html`。电脑浏览器版支持离线游玩；脚本、样式和 `assets` 素材必须与 HTML 一起保留。

## 战斗与移动

| 操作 | 按键与用途 |
| --- | --- |
| 移动 | A / D 或左右方向键 |
| 短跳、高跳、二段跳 | W / ↑ / 空格；短按低跃，按住高跃，空中可以再跳一次 |
| 四段连击 | J 连按或按住：三次轻击，接一次重击 |
| 腾空斩击 | 空中按 J |
| 向下重劈 | 空中按住 S，再按 J |
| 快速投篮球 | Q 或战场内鼠标左键；向面前投出，命中或达到射程后自动回收 |
| 格挡与招架 | 按住 L 或鼠标右键；看准攻击命中时机格挡可招架反击 |
| 冲刺 | K |
| 剑气爆发 | 能量达到 100 后按 E |
| 召唤、收回王果冻 | R；骑乘时先下骑再收回 |
| 上骑、下骑 | G；靠近坐骑并落地后使用 |
| 宝箱、出口或最终救援交互 | F；以画面提示为准 |
| 暂停、继续 | P / Esc |

触屏使用画面下方按钮。移动、防御和高跳可以按住；短按并松开跳跃键可以低跃。空中 S + J 下劈目前使用键盘操作。

## 篮球的出手与回收

篮球使用统一大小与连续位置，背负时由骑士身体自然遮挡。取球至出手约 0.12 秒，随后约 0.10 秒收招；球离手后，可以接 J 挥剑或 L 格挡打断收招。回收速度为每秒 2000 游戏像素，接回后只需约 0.12 秒准备。通常距离下，完整投球与回收不到一秒；距离、命中时机和移动会影响实际耗时。

步行、空中和骑乘均能投球；飞行期间保持一只球。篮球不消耗 E 的剑气能量。状态栏显示“快速出手、飞行、回收、接球准备”与是否可以再投。

## 生命与进度

战场左下方的生命条明确显示当前生命 / 最大生命，受伤会闪边并显示扣血数字；生命低于三成时出现提示。格挡保护面向的一侧并消耗耐力，身后的攻击仍需要转身或躲避。生命归零后可以保留成长、装备和已记录的战区进度重新挑战。

已取消需要手动按 F 的复活点旗帜。突破战区后自动保存，经过路灯自动点亮。星辉碎片与支路宝箱是额外奖励，不必每关重复收齐三枚碎片、点三次灯才能过关。清空本章战区后前往出口，按画面提示继续；最终章击败恶龙，再到囚笼前按 F 救援王子。

## 特色关卡

当前界面“本章玩法”和战役地图会标注地形及机关：树冠平台、断桥跳跃、雪岭冰带、沼泽毒池、矿道落石、熔流喷口与浮空风道等。不同敌人有不同轮廓、攻击方式和预警，按照预警选择格挡、跳跃、近战或投球。

营地可以升级长剑、银甲与护符。进度保存在当前浏览器；使用相同浏览器与地址可以继续游玩。换浏览器、清理浏览数据或移动本地文件地址，可能无法读取原地址的存档。
