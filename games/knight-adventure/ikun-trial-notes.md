# ikun 骑士 · 角色试用版

使用用户提供的铠甲小鸡参考图制作可玩的骑士外观。保留银色中分头、黄色脸与橙喙、红脸颊、篮球胸徽、黑银铠甲、黑手套和红里披风。

首页「出战形象」和游戏内暂停菜单可以选择「ikun 骑士 / 王果冻」。首次打开默认小鸡，之后记住当前浏览器的选择。更换外观沿用当前关卡、生命、金币、等级、装备和探索状态；角色偏好与冒险存档分别保存。

这是一套完整角色动作帧：手臂、手套、身体和剑在同一幅姿势中绘制，随蓄力、挥剑和收招共同变化。没有给原图叠加独立的几何手臂。

原有十二章、王德敏公主、装备成长和救出蔡乙先王子的剧情继续保留。操作：A/D 或左右箭头移动；空格二段跳；J 连击；K 冲刺；E 公主合击；F 交互；P/Esc 暂停。

离线版完整解压后打开 index.html。保留 assets 文件夹。网页和离线文件使用各自地址的浏览器存档。

素材来自内置图片生成工具，依据用户给出的参考图生成。原参考和动作图集保存在 assets；完整提示词与裁切元数据随离线包附带。
