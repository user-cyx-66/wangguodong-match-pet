# iPhone 个人安装

本包是给 iPhone 使用的原生 App，所有游戏、音乐程序和猫咪资源均随包提供。安装后无需 ChatGPT 登录，可离线玩。

`Wangguodong-iPhone-3.2.0-personal-sign.ipa` 是供你使用自己的 Apple 账号签名的设备包，尚未绑定你的账号和手机。不能在 iPhone 的文件管理器里点击它完成安装。请用 Windows 安装工具进行个人签名和安装。

1. 从 [Sideloadly 官方网站](https://sideloadly.io/) 下载 Windows 版，按官方说明准备 Apple 设备驱动/iTunes。
2. 用数据线连接 iPhone，解锁手机，按手机提示信任电脑。
3. 打开 Sideloadly，选择你的 iPhone，把本 IPA 拖进去。
4. 在这个本地工具中登录你自己的 Apple 账号，点击 Start。Apple 密码和验证码不需要发送给开发者或写进源码。
5. 安装完成后，按 iPhone 的系统提示信任对应开发者；iOS 16 及以上如提示需要开发者模式，按系统引导开启。
6. 从手机桌面的「王果冻的消消小窝」图标打开。

免费个人账号签名通常 7 天到期，需要再次刷新签名；工具可以配置自动刷新，是否成功取决于电脑运行、手机连接和 Apple 账号状态。更新/刷新请使用同一 Apple 账号和 bundle ID 覆盖安装，避免删除原 App。重要进度请在游戏设置中导出存档。

这个包没有上架 App Store，不是付费开发者账户的长期分发包，没有包含任何人的 Apple 账号、证书或私钥。签名安装需要你在自己的电脑完成账号验证。

参考：[Sideloadly 官方 FAQ](https://sideloadly.io/faq)、[AltStore Windows 安装说明](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)、[Apple 个人开发账号说明](https://developer.apple.com/help/account/basics/about-your-developer-account)。
